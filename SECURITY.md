Security
========

Please report a vulnerability privately through
[GitHub's security advisories](https://github.com/davidhirtz/website/security/advisories/new) rather than in a public
issue. Most of the code a site runs lives in its packages, [yii2-cms](https://github.com/davidhirtz/yii2-cms) and
[yii2-skeleton](https://github.com/davidhirtz/yii2-skeleton) among them: a report there reaches the same maintainer.

A project created from the template does not follow it afterwards: it gets security fixes through `composer update`
of those packages.
